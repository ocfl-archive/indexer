# NSRL Action (`nsrl`)

The `nsrl` action checks file hashes against the [National Software Reference Library (NSRL)](https://www.nist.gov/itl/ssd/software-quality-group/national-software-reference-library-nsrl) Reference Data Set (RDS) stored in an embedded BadgerDB key-value database to identify known software files, operating system binaries, and application components.

---

## Overview

In digital forensics and archival preservation, identifying known operating system and commercial software files eliminates the need for manual inspection of millions of standard files. The `nsrl` action performs microsecond lookups against a compressed BadgerDB key-value store indexed by SHA-1 digests.

### Key Capabilities
- **Capability Flags**: `ACTFILE`
- **BadgerDB Key-Value Store**: Reads snappy-compressed JSON records directly from a read-only Badger database.
- **Relational Metadata**: Resolves Product, Operating System, and Manufacturer codes (`NSRL_PROD`, `NSRL_OS`, `NSRL_MFG`) associated with file records.
- **Default Priority Weight**: `100`

---

## Execution Flow

```mermaid
flowchart TD
    A[Target File] --> B[Compute / Retrieve SHA-1 Hash]
    B --> C[Query BadgerDB for 'SHA-1-{hash}']
    C --> D{Entry Found in BadgerDB?}
    D -->|No| E[Return Empty / Unknown NSRL Record]
    D -->|Yes| F[Decompress Snappy Byte Payload]
    F --> G[Unmarshal JSON File Metadata Array]
    G --> H[Resolve Related ProductCode, OpSystemCode, MfgCode]
    H --> I[Populate ActionNSRLMeta Structure]
    I --> J[Store in ResultV2 Metadata]
    E --> J
```

---

## Configuration

In `indexer.toml`, configure the `[Indexer.nsrl]` section:

```toml
[Indexer.nsrl]
enabled = true
badger = "/var/data/indexer/nsrl_badger" # Path to BadgerDB directory containing NSRL database
```

### Configuration Fields

| Parameter | Type | Default | Description |
|---|---|---|---|
| `enabled` | `bool` | `false` | Enables or disables NSRL database lookups. |
| `badger` | `string` | `""` | Directory path containing the BadgerDB generated by `nsrl2badger`. |

---

## Building the NSRL Database

Use the bundled `nsrl2badger` command-line utility to convert official NIST NSRL RDS ISO or ZIP files into BadgerDB:

```bash
# Convert NSRL CSV data from ISO / ZIP archive to BadgerDB store
nsrl2badger -badger /var/data/indexer/nsrl_badger -in /path/to/NSRLFile.txt.zip
```

---

## Output Structure

The action populates `ResultV2`:

- `Metadata["nsrl"]`: Contains a slice of `ActionNSRLMeta` entries:
  - `File`: Map of file properties (`FileName`, `FileSize`, `CRC32`, `SpecialCode`).
  - `Prod`: Product information (`ProductName`, `ProductVersion`, `ApplicationType`).
  - `OS`: Operating system details (`OpSystemName`, `OpSystemVersion`).
  - `FileMfG` / `ProdMfg` / `OSMfg`: Manufacturer information.
